# Lottery Number Analysis（彩票选号方法 · 参数化数学科普与复现）

> **免责声明（必须保留）**：彩票开奖是**独立的随机事件**。本技能仅用于**数学 / 概率科普与教学**，
> 不构成任何投注建议，也**不改变任何一注的期望中奖概率**。理性购彩，量力而行。

本技能把彩票科普视频里的“选号方法”还原为**可复现的「输入 → 规则 / 算法 → 输出」流程 + 数学依据 + 算例**，
并用**同一套参数化框架**同时覆盖 **双色球（`ssq`）** 与 **超级大乐透（`dlt`）**，明确区分“成立 / 近似 / 不成立”的结论。

## 何时使用 / 何时不用
**使用**：
- 用户要“还原 / 讲解 / 复现”双色球、大乐透（或同类乐透）的选号方法与数学依据；
- 用户要计算某彩种的组合数、头奖概率、信息量、期望值；
- 用户要按“结构性”约束确定性选几注，并要求给出依据；
- 用户要**比较双色球与大乐透**的参数差异；
- 用户要把某条彩票科普视频固化成可复现流程。

**不要使用**：
- 预测真实开奖结果、声称能提高中奖率、保证中奖；
- 代购 / 代投注 / 诱导加注；
- 把历史开奖频率、冷热、和值、奇偶当作“可获利的规律”做投资建议。

## 参数化的两个彩种（先记住）
| 彩种 | 号码结构 | 组合数 | 头奖概率 | 信息量 | 每注期望 |
|---|---|---|---|---|---|
| 双色球 `ssq` | 红球 33 选 6 + 蓝球 16 选 1 | `C(33,6)×16 = 17,721,088` | `1/17,721,088 ≈ 5.64×10⁻⁸` | `≈ 24.08 bit` | `E = 2×51% − 2 = −0.98 元` |
| 超级大乐透 `dlt` | 前区 35 选 5 + 后区 12 选 2 | `C(35,5)×C(12,2) = 21,425,712` | `1/21,425,712 ≈ 4.67×10⁻⁸` | `≈ 24.35 bit` | `E = 2×51% − 2 = −0.98 元` |

通用规律（与具体彩种无关）：
- 组合数 = 各区组合数**相乘**；头奖概率 `P₁ = 1/N`；信息量 `H = log₂N`（比特）。
- 每注期望 `E = 单价 × 返奖率 − 单价 < 0`：**买得越多，亏损越确定**。
- 单注概率**与选哪些号无关**；“冷热 / 和值 / 奇偶”只描述**组合的分布结构**。

## 工作流（输入 → 算法 → 输出）
1. **定位**：确认是“科普 / 复现”任务，先给出上面的免责声明。
2. **算数学**：按参数表用组合公式算 `N / P₁ / H / E`，并按需做均匀性 / 独立性检验（卡方、游程、转移概率、和值分布）。
3. **要出号时**：用**结构约束**确定性挑选 —— 主区和值尽量靠近理论均值、奇偶取均衡比；全程**无随机**，可复现。
4. **出号必配解读**：输出号码的同时，输出该票的 `P₁`、`E`、信息量，并明确写出“**结构不改变中奖概率**”。
5. **标注来源**：引用视频与证据；无法核实的信息标为「待确认」。

复现命令（教学 / 自查）：
```bash
python scripts/lottery_math.py list
python scripts/lottery_math.py facts --game ssq   # 或 --game dlt
python scripts/lottery_math.py pick  --game ssq --n 3
```

## 行为红线
- 绝不说“保证中奖 / 提高中奖率 / 稳赚 / 必中”，绝不做投注诱导或“倍投回本”建议。
- 不编造未核实的方法、数据或官方比例；未知就明确标「待确认」。
- 不把历史频率、和值、奇偶当作能改变期望的“规律”——它们只描述组合的分布结构。
- 不代购 / 代投注；不涉及任何金钱交易或支付。
- 保留免责声明；引用来源与证据路径；只改与任务相关的文件。
