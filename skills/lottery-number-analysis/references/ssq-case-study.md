## 1. 方法拆解（输入 → 规则 / 算法 → 输出）

### 输入
- 红球号码池 `1..33`，每注选 **6** 个；蓝球号码池 `1..16`，每注选 **1** 个。
- 基本投注 `2 元 / 注`；目标：用 **3505 期真实开奖数据**回答“一等奖有多难、期望为何为负、模型能算什么”。

### 规则 / 算法（视频 4 大节 · 17 小节构成的推理链）
视频是一条「组合数 → 概率 / 信息量 → 数据检验 → 期望与模型极限」的推理链：

| 节 | 主题 | 视频给出的结论 |
|---|---|---|
| 1.1 | 一等奖概率：超几何分布 | 红球 33 选 6、蓝球 16 选 1；`C(33,6)=1,107,568`，`×16=17,721,088`；`P₁=1/17721088` |
| 1.2 | 信息熵：一注号码有多稀有 | `H=log₂(17,721,088)≈24.08 bit`，相当于连续猜中 **24 枚硬币**的正反面 |
| 1.3 | 期望收益：返奖率决定亏损 | 每 2 元：奖金 51%、公益金 36%、发行费 13%；`E=2×0.51−2=−0.98 元/注`，长期必然为负 |
| 1.4 | 一等奖封顶：500 万还是 1000 万 | 奖池部分 500 万 + 调节基金 500 万 = **单注封顶 1000 万**；派奖期最高 1500 万 |
| 2.1 | 红球均匀性检验（卡方） | 理论期望 `3505×6/33=637.27`；`χ²=44.91 < χ²(32,0.95)=46.19` → **无法拒绝均匀** |
| 2.2 | 蓝球均匀性检验（卡方） | 理论期望 `3505/16=219.06`；`χ²₁₅=8.97 < 24.996`，`p=0.879` → **16 个蓝球近似均匀** |
| 2.3 | 奇偶游程检验：号码没有记忆 | 实测游程 `1749`，理论 `1753.26`，`z=−0.144`，`p=0.886` → 序列**接近随机、无记忆** |
| 2.4 | 马尔可夫链：转移概率恒为 6/33 | `P(i\|i)=6/33=0.18182`；3505 期实测均值 `0.18182` → **上期号码不影响下期** |
| 3.1 | 和值分布：与理论高度吻合 | 实测均值 `100.97` ≈ 理论 `102`；实测 sd `21.13` ≈ 理论 `21.42`，偏差 < 2% |
| 3.2 | 贝叶斯更新：后验等于先验 | 先验 `6/33`；无论看多少历史数据，**后验 = 先验 ≈ 6/33**，历史无法缩小下一期不确定性 |
| 3.3 | 模型预测每期中出注数 | 超几何模型 `n≈销量/(2×17,721,088)`；三年代实测 `3.97 / 9.77 / 10.29` vs 模型 `4.01 / 9.86 / 10.38`，整体误差约 **1.1%** |
| 3.4 | 泊松假设不成立：严重过离散 | 实际中出注数波动远大于泊松；方差 / 均值 `=12.58 ≫ 1`（销量波动 + 彩民扎堆选号） |
| 4.1 | 极端期：单期最多中出 153 注 | 峰值 `153`（另有 136/117/113/108）；平均仅 `8.07 注`，`P95=22 注` → 极端值远高于常态 |
| 4.2 | 三个年代的注数演化 | 2003–2010：`3.97`（1129 期）；2011–2018：`9.77`（1227 期）；2019–2026：`10.29`（1149 期）；合计 3505 期 |
| 4.3 | 凯利准则：最优投注比例为负 | 期望为负 ⇒ 长期增长率 `g(f)<0`；**最优策略是不投注 `f*=0`** |
| 4.4 | 著名模型的检验结果 | ARIMA / LSTM / 随机森林 / 马尔可夫链预测号码**全部失败**；仅“预测注数 / 均匀性”类模型成立 |
| 4.5 | 结论：能算注数，算不出号码 | 模型能算：每期中出多少注、概率分布、长期返奖率；**算不出**：下一期是哪一注、哪个号码、好运何时出现 |

### 输出
- 一组“结构性”号码（红 6 + 蓝 1，可选）+ 对该号码的**概率 / 期望 / 信息量**定量说明。
- 核心结论：**不存在能改变中奖概率的选号法**；“冷热 / 和值 / 奇偶 / 杀号”只描述**组合的分布结构**，不改变单注命中率。

## 2. 数学依据（符号含义 + 公式）
通用符号与公式见 `method-and-math.md` §2。针对双色球：

| 量 | 公式 | 值 |
|---|---|---|
| 红球组合数 | `C(33,6)` | `1,107,568` |
| 蓝球选法 | `16` | `16` |
| 全部组合 | `N = C(33,6) × 16` | `17,721,088` |
| 头奖概率 | `P₁ = 1 / N` | `≈ 5.643×10⁻⁸` |
| 信息量 | `H = log₂N` | `≈ 24.08 bit` |
| 每注期望 | `E = 2 × 51% − 2` | `−0.98 元/注` |
| 单号期望频次 | `3505 × 6 / 33` | `637.27 次` |
| 单号重现概率 | `C(32,5)/C(33,6) = 6/33` | `0.18182` |
| 和值均值 / 标准差 | `6×17 = 102`；`σ=√(6·27/32·(33²−1)/12)` | `102 / 21.42` |
| 均匀性卡方 | `χ²=Σ(Oᵢ−Eᵢ)²/Eᵢ`，`df=32` | 临界 `46.19` |

## 3. 算例（照着能重算）
```text
C(33,6) = (33×32×31×30×29×28)/(1×2×3×4×5×6) = 797,448,960/720 = 1,107,568
N  = 1,107,568 × 16 = 17,721,088
P₁ = 1/17,721,088 ≈ 5.643×10⁻⁸
H  = log₂(17,721,088) ≈ 24.08 bit
E  = 2×0.51 − 2 = −0.98 元/注
3505 期红球单号期望 = 3505 × 6 / 33 = 637.27 次
“必中”成本 = 17,721,088 × 2 = 35,442,176 元 ≈ 3544 万；封顶 1000 万 → 净亏 ≈ 2544 万
```
一个可复现的“结构性”号码（仅供教学）：
```text
红球 03 08 14 19 25 33（和值 102、奇偶 4:2）   蓝球 07
```
> 认识点：和值 102 为偶数 ⇒ 6 个号里奇数个数必须是偶数（0/2/4/6），所以“和值=102 且奇偶 3:3”在数学上**不可能**（本例故取 4:2）；
> 该示例只是“落在高密度结构区间”的组合之一，**中奖概率与任意其它一注完全相同**（都是 `1/17,721,088`）。

## 4. 有效性评估（逐项：成立 / 近似 / 不成立）
| 结论 | 判定 | 说明 |
|---|---|---|
| `C(33,6)=1,107,568`、`×16=17,721,088` | **成立** | 组合数学直算可验证 |
| `P₁ ≈ 5.64×10⁻⁸` | **成立** | `1/N` 精确 |
| 信息量 `≈ 24.08 bit` | **成立** | `log₂N` 精确 |
| 返奖 51% / 公益 36% / 发行 13% | **待核对** | 视频口径；本技能未独立核对官方当期比例，仅按其口径算期望 |
| `E ≈ −0.98 元/注` | **成立（口径内）** | 按 `E=2×51%−2` 成立；官方奖级结构会带来细微差别，结论仍为负 |
| 红球 / 蓝球近似均匀（卡方） | **成立** | `44.91<46.19`、`χ²₁₅=8.97`，均无法拒绝均匀 |
| 号码无记忆（游程 / 转移概率） | **成立** | `z=−0.144`；`P(i\|i)=6/33=0.18182` |
| 和值近似正态、奇偶均衡占主导 | **成立（结构）** | 只描述**组合的分布结构**，不改变单注概率 |
| 超几何模型能预测每期中出注数 | **成立（注数层面）** | 误差约 1.1%；这**不是**预测号码 |
| 泊松假设不成立（过离散） | **成立** | 方差 / 均值 `12.58 ≫ 1`，中出注数波动大 |
| 凯利最优比例 `f*=0` | **成立** | 负期望下最优策略是不投注 |
| “冷热 / 和值 / 奇偶 / 杀号”能提高中奖率 | **不成立** | 只改变组合结构，不改变单注 `1/N` 概率与期望 |
| ARIMA / LSTM / RF / 马尔可夫链能预测号码 | **不成立** | 视频 4.4 亦自证“预测哪一注中的模型全部失败” |
| 存在“科学选号法”可稳定中一等奖 | **不成立** | 与 `E<0`、独立随机、均匀分布三项事实同时矛盾 |

**一句话总结**：视频给出的不是“提高中奖率的选号法”，而是**用组合数学与统计检验把“中头奖有多难、期望为何为负、
模型能算什么算不出什么”讲清楚的科普框架**；其中可复用的只有**结构分布约束**（和值≈102、奇偶均衡、多注整轮覆盖），
而它对**中奖概率无任何影响**。
