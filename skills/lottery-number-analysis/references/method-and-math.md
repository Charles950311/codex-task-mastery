# 彩票选号方法：参数化数学依据、可复现步骤与算例

> 免责声明：彩票开奖是**独立的随机事件**。本文与相关技能仅用于数学 / 概率科普与教学，**不构成任何投注建议**，
> 也**不改变任何一注的期望中奖概率**。任何“保证中奖 / 提高中奖率 / 稳赚”的说法都违背数学事实。理性购彩，量力而行。

本文件给出**一套参数化框架**：只要填入“号码区间 + 每区选几个 + 单价 + 返奖率”，就能复算任意乐透型彩种的核心量。
默认给出两个实例：**双色球 `ssq`**（红球 33 选 6 + 蓝球 16 选 1）与**超级大乐透 `dlt`**（前区 35 选 5 + 后区 12 选 2）。

---

## 1. 通用框架（输入 → 规则 / 算法 → 输出）

### 输入
- 各区号码池与选号个数：双色球 `红球 1..33 选 6` + `蓝球 1..16 选 1`；大乐透 `前区 1..35 选 5` + `后区 1..12 选 2`。
- 基本投注单价 `T`（两款均为 `2 元 / 注`）、返奖率 `r`（视频口径 `51%`）。
- 历史开奖数据（用于均匀性 / 独立性检验；双色球视频用 **3505 期**）。

### 规则 / 算法（可复现的计算链）
1. 各区组合数 `C(nᵢ, kᵢ)`，全部组合 `N = Π C(nᵢ, kᵢ)`。
2. 头奖概率 `P₁ = 1/N`；信息量 `H = log₂N`。
3. 每注期望 `E = T·r − T`；凯利最优比例 `f*`。
4. 数据检验（各彩种通用）：均匀性卡方、奇偶游程、号码转移概率、和值均值 / 标准差。
5. 结构性选号：在主区加“和值≈均值、奇偶均衡”约束，按固定次序确定性取号。

### 输出
- 上述每个量的**数值 + 公式**；一张“结构性”号码（可选）；一张**成立 / 近似 / 不成立**的有效性评估表。

## 2. 通用数学（符号含义 + 公式）

| 符号 | 含义 |
|---|---|
| `nᵢ, kᵢ` | 第 i 区的号码个数与每注选号个数（`C(n,k)` 为组合数） |
| `N` | 全部号码组合数 `= Π C(nᵢ, kᵢ)`（各组合等可能） |
| `P₁` | 头奖（各区全中）概率 |
| `H` | 头奖信息量（自信息），单位比特 |
| `T, r` | 每注单价、返奖率 |
| `E` | 每注期望收益（元 / 注） |
| `Oᵢ, Eᵢ` | 卡方检验中第 i 个号码的观测频次、理论期望频次 |
| `R, μ_R, σ_R` | 游程数、游程理论均值 / 标准差 |
| `S, σ_S` | 主区和值的均值 / 标准差 |

公式：
1. 组合数：`C(n,k) = n! / (k!(n−k)!) = [n·(n−1)…(n−k+1)] / (1·2·…·k)`
2. 全部组合：`N = Π C(nᵢ, kᵢ)`
3. 头奖概率：`P₁ = 1 / N`
4. 信息量：`H = log₂(1/P₁) = log₂ N`
5. 每注期望：`E = T·r − T`（按返奖率口径；忽略奖级结构与封顶等细节）
6. 冷热均匀期望：某区某号每期出现概率 `= k/n`，`m` 期期望出现次数 `= m·k/n`
7. 和值（无放回抽样）：`μ_S = k(n+1)/2`，`σ_S² = k·(n−k)/(n−1) · (n²−1)/12`
8. 单号重现概率：某期出现的号下期再现 `= C(n−1,k−1)/C(n,k) = k/n`
9. 奇偶比分布：`P(o 奇, k−o 偶) = C(#奇,o)·C(#偶,k−o) / C(n,k)`
10. 卡方均匀性：`χ² = Σ (Oᵢ − Eᵢ)² / Eᵢ`，自由度 `df = n − 1`，与临界值 `χ²(df, 0.95)` 比较
11. 游程检验：`z = (R − μ_R) / σ_R`；`|z| < 1.96` 时不能拒绝“无记忆 / 随机”
12. 凯利准则：期望为负时 `f* ≤ 0`，即**最优投注比例为零**（不投注）；“必中”成本 `N·T` 与头奖封顶对比可量化净亏

## 3. 两彩种参数与金标准结果

| 量 | 双色球 `ssq` | 超级大乐透 `dlt` |
|---|---|---|
| 号码结构 | 红球 `1..33` 选 6 + 蓝球 `1..16` 选 1 | 前区 `1..35` 选 5 + 后区 `1..12` 选 2 |
| 各区组合数 | `C(33,6) = 1,107,568`；`16` | `C(35,5) = 324,632`；`C(12,2) = 66` |
| 全部组合 `N` | `1,107,568 × 16 = 17,721,088` | `324,632 × 66 = 21,425,712` |
| 头奖概率 `P₁` | `5.642994×10⁻⁸ ≈ 1/1772 万` | `4.667289×10⁻⁸ ≈ 1/2143 万` |
| 信息量 `H` | `24.0790 bit` | `24.3528 bit` |
| 每注期望 `E` | `−0.98 元 / 注` | `−0.98 元 / 注` |
| 单号重现概率 `k/n` | `6/33 = 0.18182` | `5/35 = 0.14286` |
| 主区和值均值 / 标准差 | `102 / 21.42` | `90 / 21.21` |
| 卡方临界 `χ²(df, 0.95)` | `df=32 → 46.194` | `df=34 → 48.602` |

> 说明：`E = T·r − T` 为“按返奖率”的**粗略且偏乐观的近似**（真实返奖率含奖级结构与封顶，长期更差），但结论 `E < 0` 恒成立。
> 两彩种返奖率、封顶、奖级以**官方公布规则**为准；本技能不逐一展开奖级金额。

## 4. 算例（照着能重算）

### (a) 双色球：一等奖概率
```
C(33,6) = (33×32×31×30×29×28) / (1×2×3×4×5×6)
        = 797,448,960 / 720 = 1,107,568
N  = C(33,6) × 16 = 1,107,568 × 16 = 17,721,088
P₁ = 1 / 17,721,088 ≈ 5.643×10⁻⁸
H  = log₂(17,721,088) ≈ 24.08 bit   （≈ 连续猜中 24 枚硬币）
E  = 2 × 51% − 2 = −0.98 元 / 注
```
### (b) 大乐透：一等奖概率
```
C(35,5) = (35×34×33×32×31) / (1×2×3×4×5) = 38,955,840 / 120 = 324,632
C(12,2) = (12×11) / 2 = 66
N  = 324,632 × 66 = 21,425,712
P₁ = 1 / 21,425,712 ≈ 4.667×10⁻⁸
H  = log₂(21,425,712) ≈ 24.35 bit
E  = 2 × 51% − 2 = −0.98 元 / 注
```
### (c) 数据均匀性（以双色球 3505 期为例）
```
单号理论期望（红球）：E = 3505 × 6 / 33 = 637.27 次
计算 χ² = Σ (Oᵢ − Eᵢ)² / Eᵢ = 44.91
查表 χ²(32, 0.95) = 46.19；44.91 < 46.19  → 无法拒绝“均匀”的原假设
```
### (d) “必中”成本 vs 封顶（双色球）
```
必中一等奖需买下全部组合：17,721,088 × 2 元 = 35,442,176 元 ≈ 3544 万
一等奖单注封顶 1000 万 → 净亏 ≈ 2544 万；凯利最优比例 f* = 0（不投注）
```
### (e) 一个可复现的“结构性”号码（仅供教学）
```
双色球：红球 03 08 14 19 25 33（和值 102，奇偶 4:2）  蓝球 07
```
> 认识点：该号“落在高密度结构区间”，但**中奖概率与任意其它一注完全相同**（都是 `1/17,721,088`）。

## 5. 可复现的结构性选号步骤（照着做即可重算）
1. 取主区池（双色球 `1..33`，大乐透 `1..35`），枚举全部 `C(n,k)` 个主区组合。
2. 头奖组合总数 `N = Π C(nᵢ,kᵢ)` **与选哪些号无关**。
3. 加**结构约束**（只影响组合落在哪个结构区间，**不影响单注概率**）：
   - 和值尽量靠近理论均值 `k(n+1)/2`；
   - 奇偶比取最均衡的比值（如 6 选 → `3:3` 附近，5 选 → `3:2 / 2:3`）。
4. 在满足约束的组合里，按固定次序（`|和值−均值|` 升序、再字典序）取前 `k` 个 → **确定性可复现**。
5. 其余区无“结构”可优化，按字典序取（纯展示）。
6. 输出号码，并同时输出该票的 `P₁`、`E`、信息量，强调**不改变期望**。

> `scripts/lottery_math.py` 用同一套公式实现：`facts` 复算数学，`pick --game ssq|dlt --n 3` 确定性选号。

## 6. 有效性评估（逐项：成立 / 近似 / 不成立）

| 结论 | 判定 | 说明 |
|---|---|---|
| 双色球 `C(33,6)×16 = 17,721,088` | **成立** | 组合数学直算可验证 |
| 大乐透 `C(35,5)×C(12,2) = 21,425,712` | **成立** | 组合数学直算可验证 |
| `P₁ = 1/N`、`H = log₂N` | **成立** | 等可能组合 + 信息量定义，精确 |
| `E = T·r − T < 0` | **成立（口径内）** | 按返奖率口径近似；“期望永远为负”是规则事实 |
| 卡方 / 游程 / 转移概率显示开奖近似均匀、无记忆 | **成立** | 大样本检验的通用结论；单号长期频率≈`k/n` |
| 和值 / 奇偶分布近似理论（正态 / 组合分布） | **成立** | 只描述**组合的分布结构** |
| “冷热号码”可利用来提命中率 | **不成立** | 历史频率不改变下一期概率（贝叶斯后验=先验） |
| “和值 / 奇偶 / 杀号”能提高中奖率 | **不成立** | 不改变单注 `1/N` 概率与期望 |
| 存在“科学选号法”可稳定中头奖 | **不成立** | 与 `E<0`、独立随机、均匀分布三项事实同时矛盾 |
| ARIMA / LSTM / 随机森林 / 马尔可夫链预测“哪一注中” | **不成立** | 只配用于“预测每期中出多少注”，不能预测号码 |

**一句话总结**：可复算、可优化的是**组合的分布结构**（和值≈均值、奇偶均衡、多注整轮覆盖），
**不是**中奖概率；任何选号法都不能改变 `P₁ = 1/N` 与 `E < 0`。这类内容的价值在于**看清期望、理性购彩**。
