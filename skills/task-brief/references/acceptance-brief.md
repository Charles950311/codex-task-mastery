## 通过 / 不通过示例

**不合格：**
```
AC-001: 导出功能正确且安全。
```
不合格——没有场景、触发、可观察预期、禁止项、验证方法，无法判断是否满足。

**合格：**
```
AC-001: 导出生成带正确表头的文件
- 场景: 已登录用户，至少一行数据可见
- 动作: 点击“导出 CSV”
- 预期: 浏览器下载文件，列为 [id, name, created_at]
- 禁止: 泄露内部字段或他人的数据行
- 验证: 自动化集成测试 + 人工抽查表头
- 优先级: 必需
```
合格——有具体可观察结果、禁止项与验证方法，两个人能对“是否达成”达成一致。
