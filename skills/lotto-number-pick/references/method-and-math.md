## 1. 方法拆解（输入 → 规则 / 算法 → 输出）

### 输入
- 前区号码池：`1..35`，每注选 **5** 个；后区号码池：`1..12`，每注选 **2** 个。
- 基本投注 `2` 元/注；追加投注 `3` 元/注（一、二等奖追加多得基本奖金的 80%）。
- 目标：理解“中一千万头奖”的概率从何而来、有多大、钱去了哪里。

### 规则 / 算法（视频 12 小节构成的分析链）
视频把问题拆成 12 个小节（1.1–1.12），是一条「组合数 → 概率 → 奖级 → 奖金 → 期望 → 分布」的推理链：

| 节 | 主题 | 视频给出的结论 |
|---|---|---|
| 1.1 | 号码结构 | 前区 35 选 5；后区 12 选 2；两区组合数**相乘** |
| 1.2 | 组合数 | `C(35,5)=324632`，`C(12,2)=66`，总组合 `21,425,712 ≈ 2143 万` |
| 1.3 | 中奖概率 | `1/21,425,712 ≈ 4.67×10⁻⁸`；信息量 `≈ 24.35 bit/注`（≈“连中 24 枚硬币”） |
| 1.4 | 奖级结构 | 九个奖级金字塔；一等奖 `前5+后2`，逐级放宽条件、降低奖金 |
| 1.5 | 奖金分配 | 每 2 元 → 奖金返奖 51%(1.02)、公益金 36%(0.72)、发行费 13%(0.26) |
| 1.6 | 追加投注 | 多花 1 元，一/二等奖多得 80%；基本 2 元封顶 1000 万，追加 3 元封顶 1800 万；**概率不变** |
| 1.7 | 奖池水位 | 奖池 8.76 亿；一等奖 = 奖池 + 调节基金，各封顶 500 万/注，单期总额 ≤ 1 亿 |
| 1.8 | 稀有度对比 | 一等奖 ≈ 被雷击的 1/21、≈ 空难的 1/2、比双色球头奖更难 21% |
| 1.9 | 期望值 | `E = 2×51% − 2 = −0.98` 元/注；返奖率 51%，期望永为负 |
| 1.10 | 冷热号码 | 2950 期前区均值 `2950×5/35 ≈ 421.4` 次/号，极差仅 70 次 → **近似均匀，冷热不可利用** |
| 1.11 | 和值分布 | 前区 5 数和值近似正态，均值 `90`，最小 `15`、最大 `165`，极值罕见 |
| 1.12 | 奇偶比 | `3:2` 与 `2:3` 合计约 66.8%，全奇/全偶仅约 2.5%；**不改变单注概率**，只是组合分布的自然结果 |

### 输出
- 一张“结构性”大乐透号码（前区 5 + 后区 2）+ 对该号码的**中奖概率 / 期望 / 概率量级**的定量说明。
- 核心结论：**不存在能改变中奖概率的选号法**；“冷热 / 和值 / 奇偶”只描述**组合的分布结构**，不改变单注命中率。

## 2. 数学依据（符号含义 + 公式）

| 符号 | 含义 |
|---|---|
| `n`, `k` | 组合数上下标：`C(n,k)` 表示从 `n` 个不同号码里取 `k` 个的组合数 |
| `N` | 前区组合数 × 后区组合数 = 全部号码组合（等可能） |
| `P₁` | 一等奖（前区 5 个全中 + 后区 2 个全中）概率 |
| `H` | 头奖“信息量”（自信息），单位比特 |
| `E` | 每注期望收益（元/注） |
| `r` | 返奖率（视频取 51%） |
| `T` | 基本投注金额（2 元） |
| `m` | 开奖期数（用于冷热统计，视频取 2950） |

公式：
1. 组合数：`C(n,k) = n! / (k!(n−k)!) = [n·(n−1)…(n−k+1)] / (1·2·…·k)`
2. 全部组合：`N = C(35,5) × C(12,2)`
3. 头奖概率：`P₁ = 1 / N`
4. 信息量：`H = log₂(1/P₁) = log₂ N`（比特）
5. 每注期望：`E = T·r − T`（仅按返奖率估算，忽略奖级结构与头奖上限等细节）
6. 冷热均值：`x̄ = m × 5 / 35`（前区每期开出 5 个号，35 个号平分，理想均匀下每号出现次数）
7. 和值均值：`μ = 5 × (1 + 35) / 2 = 90`（等差数列均值；最小 `1+2+3+4+5=15`，最大 `31+32+33+34+35=165`）
8. 奇偶比概率：`P(k 奇, 5−k 偶) = C(18,k)·C(17,5−k) / C(35,5)`（前区 18 个奇数、17 个偶数）

## 3. 算例（照着能重算）

**(a) 全部组合与头奖概率**
```
C(35,5) = (35×34×33×32×31) / (1×2×3×4×5)
        = 38,955,840 / 120 = 324,632
C(12,2) = (12×11) / (1×2) = 132 / 2 = 66
N = 324,632 × 66 = 21,425,712
P₁ = 1 / 21,425,712 ≈ 4.667×10⁻⁸ = 0.000004667% ≈ 1/2143 万
```
（2143 万即 `21,425,712 / 10,000 ≈ 2142.6 万`，视频取整为“2143 万”。）

**(b) 头奖信息量**
```
H = log₂(21,425,712) = ln(21,425,712)/ln2 ≈ 16.880/0.6931 ≈ 24.35 (bit)
```
含义：头奖“罕见度”相当于**连续抛硬币命中 24.35 个指定结果**（≈ 1/2²⁴·³⁵）。

**(c) 每注期望（按返奖率 51%）**
```
E = 2 × 0.51 − 2 = 1.02 − 2 = −0.98 (元/注)
```
即平均每买 1 注亏损 0.98 元，返奖率 51% ⇒ 期望永远为负。

**(d) 冷热均值**
```
x̄ = 2950 × 5 / 35 = 14,750 / 35 ≈ 421.4 (次/号)
```
视频实测出现最多的号 458 次、最少的号 388 次，极差 `458−388=70` 次，波动约 `70/2950 ≈ ±2.4%`，统计上近似均匀。

**(e) 和值均值与极值**
```
μ = 5 × (1+35)/2 = 5 × 18 = 90
min = 1+2+3+4+5 = 15
max = 31+32+33+34+35 = 165
```

**(f) 奇偶比（精确值，供对照视频）**
```
P(5:0) = C(18,5)C(17,0)/324632 = 8,568 / 324,632 = 2.64%
P(4:1) = C(18,4)C(17,1)/324632 = 52,020 / 324,632 = 16.02%
P(3:2) = C(18,3)C(17,2)/324632 = 110,976 / 324,632 = 34.19%
P(2:3) = C(18,2)C(17,3)/324632 = 104,040 / 324,632 = 32.05%
P(1:4) = C(18,1)C(17,4)/324632 = 42,840 / 324,632 = 13.20%
P(0:5) = C(17,5)/324632       = 6,188 / 324,632 = 1.91%
```
视频展示为对称的 `2.5 / 14.9 / 33.4 / 33.4 / 14.9 / 2.5(%)`（合计 `3:2`+`2:3 ≈66.8%`）。
因前区有 **18 个奇数、17 个偶数**，奇偶并不完全对称：**精确值存在小数差**（如 `3:2` 实为 34.19%、`2:3` 实为 32.05%）。视频为便于展示做了对称化近似，但结论（`3:2/2:3` 占主导、极值罕见、不改概率）成立。

**(g) 一个可复现的“结构性”号码示例**
```
前区：07 13 20 24 26    → 和值 = 90，奇偶 = 2:3（2 奇 3 偶）
后区：04 09
```
> 认识点：和值 90 是偶数 ⇒ 5 个号里奇数个数必须是偶数（0/2/4），所以**“和值=90 且奇偶 3:2”在数学上不可能**。
> 该示例只是“落在高密度结构区间”的众多组合之一，**中奖概率与任意其它一注完全相同**（都是 1/21,425,712）。

## 4. 可复现的结构性选号步骤（照着做即可重算）
1. 取前区池 `1..35`，用 `combinations(1..35, 5)` 枚举全部 324,632 个前区组合。
2. 头奖概率相关的**组合总数**：`N = C(35,5)·C(12,2) = 21,425,712`（与具体选哪些号无关）。
3. 若按视频的“结构分布”挑号，可加两条**结构约束**（注意：只影响“组合落在哪个结构区间”，不影响单注概率）：
   - 和值尽量靠近均值 `90`；
   - 奇偶比取 `3:2` 或 `2:3`。
4. 在满足约束的组合里，按固定次序（如 `|和值−90|` 升序、再按字典序）取前 `k` 个 → 结果**确定性可复现**。
5. 后区从 `C(12,2)=66` 个组合中按字典序取（后区无“结构”可优化，纯属展示）。
6. 输出前区 5 个 + 后区 2 个，并同时输出该票的 `P₁`、`E`、信息量，强调**不改变期望**。

> `scripts/structural_pick.py` 用同一套公式实现上述步骤，可 `python structural_pick.py facts` 复算数学、`python structural_pick.py pick --n 3` 确定性选号。

## 5. 有效性评估（逐项：成立 / 近似 / 不成立）
| 结论 | 判定 | 说明 |
|---|---|---|
| `C(35,5)=324632`、`C(12,2)=66`、`N=21,425,712` | **成立** | 组合数学直算可验证 |
| `P₁ ≈ 4.67×10⁻⁸` | **成立** | `1/N` 精确 |
| 信息量 `≈24.35 bit` | **成立** | `log₂N` 精确 |
| 返奖 51% / 公益 36% / 发行 13% | **待核对** | 视频所述比例；本技能未独立核对官方当期比例，仅按视频口径计算期望 |
| `E ≈ −0.98 元/注` | **成立（口径内）** | 按 `E=2×51%−2` 成立；官方奖级结构会带来细微差别 |
| 追加多拿 80%、封顶 1800 万、概率不变 | **成立** | “只加奖金不加概率”是规则事实 |
| 奖池 ≥1 亿时头奖可破亿、单注封顶 | **成立（规则层面）** | 与官方玩法规则一致 |
| “冷热号码”可利用来提命中率 | **不成立** | 2950 期近似均匀（极差仅 ~2.4%），历史频率无预测力 |
| “和值/奇偶”能提高中奖率 | **不成立** | 只改变组合的**分布结构**，不改变单注 `1/N` 概率与期望 |
| “存在科学选号法可中一千万” | **不成立** | 与 `E<0`、独立随机、均匀分布三项事实同时矛盾 |

**一句话总结**：视频给出的不是“提高中奖率的选号法”，而是**用组合数学与概率把“中头奖有多难、期望为何为负”讲清楚的科普框架**；
其中可作为“选号”复用的只有**结构分布约束**（和值≈90、奇偶 3:2/2:3），而它对**中奖概率无任何影响**。

**全量求真结论（可证伪）**：

1. 单号层面不可预测：全量前区卡方 χ²=89.4（p≈0）的偏离集中在**早期非平稳段**（07001~12025，χ²=180.3），

3. 唯一概率杠杆是**结构**：三注前区 15 号 / 后区 6 号互不重叠 → P(至少中一注) 全局最优 **19.689%**。
