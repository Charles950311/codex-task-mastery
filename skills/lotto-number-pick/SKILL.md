# Lotto Number Pick（大乐透选号方法 · 数学科普与复现）

> **免责声明（必须保留）**：彩票开奖是**独立的随机事件**。本技能仅用于**数学/概率科普与教学**，不构成任何投注建议，
> 也**不改变任何一注的期望中奖概率**。理性购彩，量力而行。

本技能把一个彩票科普视频（鲁班科普《如何中大乐透一千万头奖？》）里的“选号方法”还原为
**可复现的「输入 → 规则/算法 → 输出」流程 + 数学依据 + 算例**，并明确区分“成立 / 近似 / 不成立”的结论。

## 何时使用 / 何时不用
**使用**：
- 用户要“还原 / 讲解 / 复现”大乐透（或同类乐透）的选号方法与数学依据；
- 用户要计算大乐透的组合数、头奖概率、信息量、期望值；
- 用户要按“结构性”约束（和值≈90、奇偶 3:2 或 2:3）确定性选几注，并要求给出依据；
- 用户要把某条彩票科普视频固化成可复现流程。

**不要使用**：
- 预测真实开奖结果、声称能提高中奖率、保证中奖；
- 代购 / 代投注 / 诱导加注；
- 把历史开奖频率当作“可获利的规律”做投资建议。

> 注：本技能面向“超级大乐透”（前区 35 选 5、后区 12 选 2、基本投注 2 元/注）。其他玩法（如双色球 33 选 6 + 蓝球 16 选 1）结构不同，需另算组合数。

## 核心事实（先记住）
- **组合数**：`N = C(35,5) × C(12,2) = 324,632 × 66 = 21,425,712 ≈ 2143 万`
- **头奖概率**：`P₁ = 1/N ≈ 4.667×10⁻⁸`；**信息量** `H = log₂N ≈ 24.35 bit`
- **每注期望**（返奖率 51%）：`E = 2×51% − 2 = −0.98 元/注`（期望永远为负）
- **冷热不可用**：2950 期均值 `2950×5/35 ≈ 421 次/号`，近似均匀（极差仅约 ±2.4%）
- **和值**：前区 5 数和值近似正态，均值 `90`（最小 `15` / 最大 `165`）
- **奇偶**：`3:2` 与 `2:3` 占主导（精确 34.19% / 32.05%）；**结构特征不改变单注概率**

## 工作流（输入 → 算法 → 输出）
1. **定位**：确认是“科普/复现”任务，先给出上面的免责声明。
2. **算数学**：用组合公式算 `N / P₁ / H / E` 等（公式与推导见 `references/method-and-math.md` §2–3）。
3. **要出号时**：用**结构约束**确定性挑选 —— 和值尽量靠近 `90`、奇偶取 `3:2` 或 `2:3`，后区按字典序；
   全程**无随机**，可复现。
4. **出号必配解读**：输出号码的同时，输出该票的 `P₁`、`E`、信息量，并明确写出“**结构不改变中奖概率**”。
5. **标注来源**：引用视频与证据（`references/source-evidence.md`）；无法核实的信息标为「待确认」。

复现命令（教学/自查）：
```bash
python scripts/structural_pick.py facts        # 打印全部核心数学量（可与公式逐项对照）
python scripts/structural_pick.py pick --n 3   # 确定性生成 3 注结构性号码
```
