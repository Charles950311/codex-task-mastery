# 商业项目对标报告 · 2026-10-24

> 目的：拿本仓库（Codex Task Mastery 技能包 + 项目开展提示词）与官方规范及主流商业实践对比，找出差距，取长补短。
> 检索日期：2026-10-24。来源见文末。

## 一、对标对象与核心机制

| 对标对象 | 性质 | 核心机制 | 值得借鉴的点 |
|---|---|---|---|
| Agent Skills 官方规范（agentskills.io） | 开放规范（Anthropic 生态主导，Claude Code / Codex 均兼容） | frontmatter（name/description 必填 + license/compatibility/metadata/allowed-tools 可选）、渐进披露三段式、scripts/references/assets 目录约定、官方校验器 | **可机器校验的规范**：name 命名规则、description ≤1024 字符、SKILL.md <500 行 |
| OpenAI Codex（learn.chatgpt.com/docs/build-skills） | 商业产品 | 技能文件夹 + SKILL.md frontmatter，本地/仓库级技能直接挂载 | 仓库内即技能源；AGENTS.md 作为仓库级约定入口 |
| AGENTS.md 开放标准（agents.md） | 开放标准（60k+ 项目采用） | 仓库根放一份简洁的 AGENTS.md：构建/测试命令 + 约定 | **跨智能体通用入口**：Codex / ZCode / Cursor / Gemini CLI 等都读它 |
| Cursor Rules（cursor.com/docs/rules） | 商业产品 | Always / Auto Attached(glob) / Agent Requested(description) / Manual 四类规则 | always-on 保持极简、按需加载优先；规则总量控制在千词级，超大反而稀释遵从度 |
| awesome-cursorrules 等社区模板库 | 开源社区 | 按框架分类的现成规则模板 | 「模板库」形态：按任务类型给可复制骨架（我们已有 prompt-patterns） |

## 二、逐项差距判定（✅ 已达标 / ⚠️ 部分差距 / ❌ 缺失）

| # | 实践 | 商业标准 | 本仓库现状 | 判定 |
|---|---|---|---|---|
| 1 | name 命名规则（小写字母数字+单连字符，1-64 字符，与目录名一致） | spec 强制 | 10/10 合规（已程序化核验） | ✅ |
| 2 | description ≤1024 字符、含"做什么+何时用+何时不用" | spec 强制 + 推荐 | 最长 477 字符，全部带触发词与不用场景，中英双语 | ✅ |
| 3 | SKILL.md <500 行，长内容进 references/ | spec 推荐 | 全部 <100 行，渐进披露结构完整 | ✅ |
| 4 | scripts 自包含、明确依赖 | spec 推荐 | 两个脚本均纯标准库，实测跑通、输出与文档一致 | ✅ |
| 5 | **规范校验工具**（官方有校验器；Cursor 生态有规则检查） | 应有 | 无 → 本次补 `lint-skills.py`（按官方 spec 规则实现） | ❌→✅ |
| 6 | **AGENTS.md 仓库级入口**（60k+ 项目采用的跨智能体标准） | 应有 | 无 → 本次补根目录 AGENTS.md | ❌→✅ |
| 7 | **维护手册 / 贡献指南**（成熟开源项目标配） | 应有 | 无 → 本次补 MAINTENANCE.md（同步清单+新增技能流程+触发自测） | ❌→✅ |
| 8 | 触发质量评估（官方建议用测试对话验证技能被正确触发） | 推荐 | 无 → 以轻量「触发自测用例表」入 MAINTENANCE.md（每技能 2-3 条话术） | ⚠️→✅（轻量版） |
| 9 | 安装/同步工具 + 漂移检测 | 多数技能包只给手工复制命令 | install-skills.ps1 双模式，已实测（优于多数对标对象） | ✅＋ |
| 10 | 版本管理与变更记录 | 标配 | git + CHANGELOG + 双层版本（仓库 semver / 提示词 vX.Y） | ✅ |
| 11 | 仓库 LICENSE / 技能 license 元数据 | 规范有可选 license 字段 | 无 LICENSE 文件 | ⚠️ 待用户定（法律决定不代做） |
| 12 | metadata 字段存版本等信息 | spec 可选 | 未用；仓库级 CHANGELOG 已覆盖，按技能维护版本成本>收益 | ⏸️ 有意不采用 |
| 13 | always-on 内容极简 | Cursor 共识 | 全部技能按 description 触发，无常驻大块规则 | ✅ |
| 14 | 面向多智能体通用 | 各家私有格式收敛于 AGENTS.md + Agent Skills | 提示词 v1.2 已跨 harness 化，技能目录为双生态兼容格式 | ✅ |

## 三、本次落地动作

1. **`lint-skills.py`**：按官方 spec 实现校验（name 规则 / description 长度 / 行数上限 / 引用文件存在 / 孤儿文件告警），错误时退出码 1，可接 CI；附正反两向测试。
2. **`AGENTS.md`**（仓库根）：跨智能体通用入口——仓库布局、验证命令、改动纪律。
3. **`MAINTENANCE.md`**：版本规则、改技能/新增技能/提示词派生三份同步清单、每技能触发自测用例。
4. **README 专业化升级**：仓库全景（技能包+提示词+工具+研究四类资产）、快速上手、维护入口链接。
5. **不做的**：LICENSE（待用户决定）；按技能 metadata 版本号（CHANGELOG 已覆盖）；技能内容重写（审计无质量问题，保持最小改动）。
